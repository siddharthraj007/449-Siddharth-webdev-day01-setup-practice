When I enter a website URL in the browser, it uses DNS (Domain Name System) to find the server's IP address. The browser then sends a request to that server to
access the webpage. The server responds by sending files such as HTML, CSS, JavaScript, and images. The browser reads the HTML to understand the page structure,
uses CSS to style the content, and runs JavaScript to add interactive features. If additional resources are needed, the browser requests them from the server.
Finally, it combines everything and displays the webpage on the screen.
